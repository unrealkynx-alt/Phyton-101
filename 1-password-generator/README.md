# Password Generator

A CLI Python script that generates randomized passwords containing uppercase letters, lowercase letters, numbers, and symbols.

## How to Run

1. Make sure Python 3 is installed.
2. Open your terminal in this directory.
3. Run the script:
   ```bash
   python password_gen.py
   ```
4. Enter the desired password length when prompted.

## Features

- Custom password length defined by user input
- Includes characters from:
  - Uppercase and lowercase ASCII letters
  - Digits (0-9)
  - Standard punctuation / special characters

## Concepts Practiced

- Importing standard library modules (`random`, `string`)
- String constants (`string.ascii_letters`, `string.digits`, `string.punctuation`)
- Functions with parameters and return values
- Type casting (`int()`)
- For loops and `range()`
- String concatenation
